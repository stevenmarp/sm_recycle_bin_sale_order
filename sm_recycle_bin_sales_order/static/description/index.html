🗑️ Recycle Bin - Sales Order

Track and audit all deleted Sales Orders with complete information including IP address, user details, and deletion timestamp

Odoo 18 Enterprise & Community

Screenshots

📍 Menu Location

Access the Recycle Bin from Sales → Configuration → Recycle Bin. Only Sales Managers can view this menu.

📊 List View

View all deleted Sales Orders in a comprehensive list with SO number, customer, amount, deletion date, user who deleted, and IP address. Use filters to find deletions by date, user, or IP.

📝 Form View

Detailed view of a deleted Sales Order showing complete information including original order lines summary, user agent, and deletion timestamp.
